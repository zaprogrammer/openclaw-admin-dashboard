## Codebase Patterns
- Use `'use client'` directive for components with React hooks (useState, useEffect)
- Styling: Use Tailwind CSS with CSS variables from globals.css (e.g., `bg-[#3b82f6]` for accent)
- Agent types are defined in `@/types/agent.ts`
- Agent utilities (loadAgents, getSkillCount, createAgent, deleteAgent) are in `@/lib/agents.ts`
- API routes go in `src/app/api/[route]/route.ts` (Next.js App Router convention)
- Components directory: `src/components/`
- Modal pattern: use `isOpen` prop for visibility, reset state in `useEffect` when opening
- Dropdown menu pattern: use absolute positioning with z-index and backdrop click handler to close
- Event propagation: use `e.stopPropagation()` to prevent nested button clicks from triggering parent onClick
- DELETE endpoints: use query parameters (`?name=value`) instead of request body
- API mutations: return created/updated entity so client can use it immediately
- Use `useCallback` for functions in useEffect dependencies to avoid infinite loops
- PUT endpoints: use request body for data (e.g., currentName, newName), return updated entity
- Rename validation: exclude current entity from duplicate check when renaming
